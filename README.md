## Этот сайт предназначен для ознакомления с городами России и их достопримечательностями.
### Есть возможность регистрации на сайте, делиться впечатлениями о городах и устанавливать рейтинг города.


Простое Django-приложение с интеграцией Telegram-бота для отправки уведомлений о действиях в административной панели. Решение упаковано в Docker-контейнеры для быстрого развёртывания и удобной эксплуатации.

🌐 Описание проекта

Проект представляет собой полноценное Django-приложение с поддержкой Telegram-бота, выполняющего две основные функции:

    Регистрация новых подписчиков через команду /start.
    Рассылка уведомлений подписчикам о любом успешном входе администратора в Django Admin.

Вся логика реализована таким образом, чтобы обеспечить надёжность, удобство поддержки и возможность лёгкого расширения функционала.

🛠️ Требования

Перед началом убедитесь, что у вас установлены:

    Docker (для сборки и запуска контейнеров)
    Docker Compose (для управления составными проектами)

Также нужен токен Telegram-бота и настроенная базовая конфигурация PostgreSQL (логин, пароль, имя базы данных).

⭐ Инструкция по запуску
1. Клонирование репозитория

Скопируйте проект себе на компьютер:

    git clone https://github.com/MaksLevchenko/country_of__impressions.git
    cd country_of__impressions

2. Настройка переменных окружения

Переименнуйте файлы .env.dev в .env.docker, а .env.loc в .env и укажите необходимые переменные:

    POSTGRES_DB=<Название вашей базы данных>

    POSTGRES_USER=<Пользователь вашей базы данных>

    POSTGRES_PASSWORD=<Пароль вашей базы данных>

    TG_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN_HERE

    DJANGO_SETTINGS_MODULE=My_travel_project.settings

    django_key=<Секретный ключ от вашего приложения Django>


Замените значение YOUR_TELEGRAM_BOT_TOKEN_HERE на реальный токен вашего Telegram-бота.
## DJANGO_SETTINGS_MODULE и ENVIRONMENT эти переменные оставьте какие они есть.

3. Сборка и запуск Docker-образов

Используйте следующие команды для сборки образа и запуска контейнеров:

    docker-compose build
    docker-compose up -d


Эти команды соберут Docker-образы и запустят контейнеры в фоновом режиме. Процесс займет некоторое время в первый раз.
Затем надо применить миграции командой:

    docker-compose exec travel python manage.py migrate

Теперь создадим нашего суперюзера командой:

    docker-compose exec travel python manage.py createsuperuser

Следуйте указаниям в терминале!

4. Использование приложения

Откройте браузер и перейдите по адресу http://localhost:8000/, чтобы увидеть работающее Django-приложение.

Подключайтесь к своему Telegram-боту, введя команду /start. После подтверждения регистрации вы будете получать уведомления о любых успешных входах в административную панель Django.

✨ Дополнительная настройка
Миграции базы данных

Если вы внесли изменения в модели Django, примените миграции с помощью следующей команды:

    docker-compose exec travel python manage.py migrate

Если вам нужно внести изменения в код, используйте режим перезагрузки разработчика:

    docker-compose down
    docker-compose up --build --force-recreate

Или воспользуйтесь отдельной командой запуска Django для быстрой итерации изменений:

    docker-compose exec travel python manage.py runserver 0.0.0.0:8000

Приятного использования!
